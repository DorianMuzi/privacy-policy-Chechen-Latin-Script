Règles de confidentialité

Extension : Chechen Latin Script
Version : 1.0
Dernière mise à jour : avril 2025

1. Objectif unique

L’extension Chechen Latin Script a un seul objectif :

➡️ Transcrire automatiquement le texte tchétchène en écriture cyrillique vers l’alphabet latin de 1992 sur les pages web visitées par l’utilisateur.

2. Données collectées

✅ Aucune donnée personnelle n’est collectée.

  • Aucune donnée de navigation, historique ou contenu personnel n’est collectée.
  • Aucune information n’est transmise à des serveurs externes.
  • Aucun compte ni identifiant utilisateur n’est requis.

3. Données stockées localement

L’extension utilise le stockage local (chrome.storage) uniquement pour sauvegarder certaines préférences :

  • L’état de l’option Transcription automatique.

Ces données restent locales à l’appareil et ne sont jamais partagées.

4. Accès aux sites web

L’extension demande un accès aux pages web visitées (<all_urls>) pour :

  • Lire le texte visible contenant du tchétchène en cyrillique.
  • Le convertir en alphabet latin localement, sans modifier la page source.

5. Sécurité et respect de la vie privée

  • Le code est exécuté entièrement en local.
  • Pas de traqueurs, de publicité, ni d’analyse comportementale.
  • Seulement les permissions strictement nécessaires sont demandées.

6. Contact

Pour toute question, veuillez contacter le développeur à :
📧 chechenlatinscript@gmail.com

Privacy Policy

Extension: Chechen Latin Script
Version: 1.0
Last updated: April 2025

1. Single Purpose

The Chechen Latin Script extension has one sole purpose:

➡️ Automatically transcribe Chechen text written in Cyrillic script into the 1992 Latin alphabet on web pages visited by the user.

2. Data Collection

✅ No personal data is collected.

  • No browsing history, page content, or personal data is gathered.
  • No data is sent to any external server.
  • No account or user ID is required.

3. Local Storage

The extension uses Chrome’s local storage (chrome.storage) only to save user preferences such as:

  • Whether automatic transcription is enabled or not.

These preferences are stored locally on the user's device and are never shared.

4. Site Access

The extension requests access to all webpages (<all_urls>) only to:

  • Read visible text that may contain Chechen written in Cyrillic.
  • Convert it locally into Latin script without altering the actual page content.

5. Privacy & Security

  • The extension code runs entirely on the user's device.
  • No tracking, no ads, and no behavioral analysis are performed.
  • Only the minimal required permissions are requested.

6. Contact

If you have any questions, you may contact the developer at:
📧 chechenlatinscript@gmail.com
